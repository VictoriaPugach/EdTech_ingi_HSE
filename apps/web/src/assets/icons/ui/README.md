# UI Icons

SVG иконки для UI-компонентов (инпуты, кнопки, навигация и т.д.).

## Рекомендуемый формат

- Формат: `.svg`
- Размер viewBox: `0 0 24 24`
- Стиль: outline (незакрашенные) или solid (закрашенные)
- Источник: [Heroicons](https://heroicons.com/) или [Lucide](https://lucide.dev/)

## Нужные иконки

| Файл                 | Назначение                        |
|----------------------|-----------------------------------|
| `email.svg`          | Поле ввода email                  |
| `lock.svg`           | Поле ввода пароля                 |
| `eye.svg`            | Показать пароль                   |
| `eye-off.svg`        | Скрыть пароль                     |
| `check.svg`          | Чекбокс, статус успеха            |
| `x.svg`              | Закрыть, удалить                  |
| `chevron-down.svg`   | Раскрывающиеся списки             |
| `search.svg`         | Поиск                             |
| `user.svg`           | Профиль пользователя              |
| `logout.svg`         | Выход из аккаунта                 |
| `menu.svg`           | Мобильное меню                    |
| `bell.svg`           | Уведомления                       |
| `settings.svg`       | Настройки                         |
