# Logo

Логотип платформы в различных форматах.

## Нужные файлы

| Файл                  | Назначение                                 |
|-----------------------|--------------------------------------------|
| `logo.svg`            | Основной логотип (SVG, масштабируемый)     |
| `logo-dark.svg`       | Версия для тёмного фона                    |
| `logo-icon.svg`       | Только иконка без текста (favicon, avatar) |
| `logo.png`            | Растровая версия 512×512 (OG-теги)         |

## Рекомендации

- Фирменный цвет: `#7B5BF4` (фиолетовый) + `#BFE5CF` (зелёный)
- Минимальный размер для отображения: 32px по высоте
