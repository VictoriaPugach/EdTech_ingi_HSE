# Feature Icons

Иконки для функциональных блоков платформы (преподаватель, ученик, курсы и т.д.).

## Рекомендуемый формат

- Формат: `.svg` или `.png` (2x для ретина)
- SVG viewBox: `0 0 48 48` (крупные иллюстративные иконки)
- Стиль: цветные, в стиле 3D flat (как в макете)

## Нужные иконки

| Файл                    | Назначение                              |
|-------------------------|-----------------------------------------|
| `teacher.svg`           | Роль «Преподаватель» (иконка шапочки)   |
| `student.svg`           | Роль «Ученик» (рюкзак)                  |
| `trophy.svg`            | Достижения и прогресс                   |
| `lightbulb.svg`         | Умные подсказки                         |
| `people.svg`            | Учись вместе                            |
| `shield.svg`            | Безопасная среда                        |
| `cloud.svg`             | Онлайн обучение                         |
| `code.svg`              | Код / программирование                  |
