# Backgrounds

Фоновые изображения и паттерны для страниц.

## Нужные файлы

| Файл                    | Назначение                                   |
|-------------------------|----------------------------------------------|
| `pattern-dots.svg`      | Паттерн с точками (декоративный фон)         |
| `gradient-hero.svg`     | Градиентный фон для hero-секции              |

## Рекомендации

- Фоновые SVG-паттерны предпочтительнее растровых (масштабируемость)
- Цвета: оттенки `#F0F2FA`, `#EDE9FE`, `#E8F7EF`
