# Illustrations

3D-иллюстрации для страниц платформы.

## Рекомендуемый формат

- Формат: `.png` (прозрачный фон) или `.webp`
- Разрешение: минимум 800px по большей стороне, 2x версия для ретина
- Стиль: 3D flat, персонажи в фиолетово-зелёной гамме (как в макете)

## Нужные иллюстрации

| Файл                        | Где используется                         | Размер    |
|-----------------------------|------------------------------------------|-----------|
| `hero-coding.png`           | Страница входа — левая панель            | ~560×400px |
| `hero-coding@2x.png`        | Retina-версия hero-coding                | ~1120×800px |
| `empty-sessions.png`        | Страница «Мои сессии» — нет сессий      | ~320×240px |
| `achievement-unlock.png`    | Попап достижения                         | ~240×240px |

## В макете

Главная иллюстрация на странице входа:
- Два персонажа (мальчик и девочка) за ноутбуками
- Робот-ассистент справа  
- Экран с кодом по центру
- Фон: светло-фиолетовый круг (#EDE9FE)
