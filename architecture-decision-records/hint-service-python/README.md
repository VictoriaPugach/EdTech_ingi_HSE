# Использование Python и FastAPI для Hint Service

Дата создания: 18.02.2026
Статус: Принято

## Контекст

Hint Service принимает снимок кода или контекст ошибки из активной сессии, анализирует его, классифицирует тип проблемы и возвращает педагогическую подсказку в формате JSON с полями message, location и visualCue. Основной язык анализа: Python. Требование по задержке: p95 < 2000 мс на запрос. Сервис является независимым и не участвует в CRDT-потоке.

## Рассмотренные варианты

Node.js + tree-sitter-node. Пакет tree-sitter для Node.js существует, но нативные биндинги для Python-грамматики менее стабильны в экосистеме Node.js, чем аналогичный пакет py-tree-sitter. Кроме того, ML-библиотеки для потенциального усиления подсказок (transformers, sentence-transformers) либо отсутствуют в экосистеме Node.js, либо требуют вызова Python-процесса как подпроцесса.

Go + tree-sitter-go. Биндинги Go для Tree-sitter доступны, но экосистема ML-инструментов и текстовых шаблонов значительно беднее. Интеграция с LLM-клиентами требует REST-обёртки.

Python + FastAPI. py-tree-sitter является официальным Python-биндингом Tree-sitter с наибольшей зрелостью и наибольшим числом поддерживаемых грамматик. FastAPI обеспечивает асинхронный HTTP-сервер с автоматической валидацией схем через Pydantic и автоматической генерацией OpenAPI-спецификации. Python является основным языком научного стека и библиотек для NLP и LLM-интеграций.

## Решение

Hint Service реализован на Python 3.12 с FastAPI в качестве HTTP-фреймворка. Разбор AST выполняется через py-tree-sitter с грамматикой Python. Ответ сервиса соответствует Pydantic-модели HintResponse с полями message (строка подсказки), location (номер строки), visualCue (тип визуального индикатора). Сервис запускается как самостоятельный контейнер и взаимодействует с клиентом через REST POST /hint.

## Обоснование

py-tree-sitter обеспечивает детерминированный парсинг Python-кода в AST за время, как правило, менее 10 мс для файлов типичного учебного объема. Это гарантирует укладывание в требование 2000 мс на запрос даже с учетом сетевых задержек.

Python 3.12 позволяет без дополнительной инфраструктуры интегрировать LLM-клиент (openai, anthropic, huggingface) если потребуется усиление подсказок за пределами AST-базового подхода. На этапе MVP LLM является опциональным компонентом, который мокируется в автотестах. AST-first подход обеспечивает предсказуемую задержку.

FastAPI автоматически генерирует OpenAPI-схему из Pydantic-моделей, что упрощает документирование контракта сервиса. Асинхронный режим FastAPI позволяет обрабатывать несколько параллельных запросов без блокировки, что важно при нескольких одновременных сессиях.

Независимый контейнер Hint Service не влияет на задержку CRDT-синхронизации. Если Hint Service временно недоступен или медленно отвечает, пользователи продолжают работать в редакторе без прерывания. Клиент реализует debounce и timeout при запросе подсказки.

## Последствия

Hint Service не имеет состояния и не хранит данные о сессии между запросами. Каждый запрос содержит полный контекст: код, язык, тип события. Это упрощает горизонтальное масштабирование сервиса при необходимости.

При добавлении новых анализируемых языков (JavaScript, Lua) требуется добавить соответствующую грамматику Tree-sitter и обновить справочник шаблонов ошибок. Изменение не затрагивает остальные сервисы.

## Риски

py-tree-sitter требует компиляции нативных расширений при сборке Docker-образа. Снижение риска: использование официального базового образа python:3.12-slim с предустановленными build tools в Dockerfile.

Зависимость от внешнего LLM API при использовании опционального усиления подсказок создает риск недоступности. Снижение риска: graceful degradation до AST-базовых шаблонных подсказок при недоступности LLM.

## Оценка результативности

Сервис считается корректно реализованным, если тесты Pytest подтверждают, что синтаксические ошибки в Python-коде классифицируются правильно в 100 процентах тестовых случаев, p95-задержка ответа на запрос подсказки не превышает 2000 мс, и подсказки получают оценку педагога не ниже 4/5 в не менее 80 процентах случаев при экспертной проверке.
