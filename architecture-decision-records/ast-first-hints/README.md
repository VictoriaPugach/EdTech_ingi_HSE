# AST-first подход к генерации педагогических подсказок

Дата создания: 26.02.2026
Статус: Принято

## Контекст

Hint Service должен генерировать понятные учебные подсказки для детей 10-14 лет при обнаружении ошибки или затруднения в коде. Требования: предсказуемая задержка p95 < 2000 мс, язык подсказки педагогически безопасен и не содержит технического жаргона, сервис работает без постоянной зависимости от внешнего API при базовых сценариях, подсказка привязана к конкретной строке кода.

## Рассмотренные варианты

Полностью LLM-based подход: каждый запрос подсказки отправляется в LLM API (OpenAI GPT, Anthropic Claude или локальная модель). Плюсы: гибкие формулировки, потенциально высокое качество объяснений. Минусы: задержка LLM API варьируется от 500 мс до нескольких секунд и неподконтрольна, зависимость от внешнего сервиса нарушает требование об устойчивости к отказам внешних API, стоимость при большом числе запросов в учебном контексте.

Regex-анализ текста кода без построения AST: простая реализация, но высокая частота ложных срабатываний и пропуска ошибок из-за неструктурированного разбора. Не позволяет точно привязать ошибку к строке и токену.

AST-анализ через Tree-sitter с детерминированными шаблонами подсказок: парсер строит дерево синтаксиса за несколько миллисекунд, Error Detector классифицирует тип проблемы по узлам AST, Hint Generator выбирает шаблон из справочника адаптированных подсказок для новичков. LLM используется как опциональный слой переформулировки для нестандартных случаев.

## Решение

Принят AST-first подход: основным механизмом анализа является Tree-sitter, основным механизмом генерации текста является справочник шаблонов. Шаблоны составлены для наиболее частых ошибок новичков в Python: синтаксические ошибки, пропущенное двоеточие, неверный отступ, необъявленная переменная, несовпадение типов в простых выражениях, ошибка при вызове функции с неверным числом аргументов.

LLM подключается как необязательный второй слой в следующих случаях: тип ошибки не распознан шаблонным справочником, и администратор включил LLM-режим в конфигурации. В автотестах LLM мокируется.

Формат ответа: JSON с полями message (адаптированный текст для ребенка без технического жаргона), location (номер строки и столбца), severity (info/warning/error), visualCue (тип значка в UI).

## Обоснование

Детерминированность задержки критична для учебного контекста. Ребенок ждет реакции интерфейса после остановки ввода. Если ответ занимает 3-5 секунд из-за медленного LLM, педагогический эффект подсказки снижается. AST-анализ занимает от 5 до 50 мс, формирование шаблона менее 1 мс. Суммарная задержка в рамках одного сервиса не превышает 100 мс при стандартном объеме кода.

Автономность работы без внешних API соответствует требованию заказчика об устойчивости платформы к отказам внешних сервисов. Система должна продолжать работать при отсутствии доступа к LLM API.

Шаблонные подсказки поддаются педагогической проверке и редактированию. Преподаватели могут просмотреть и скорректировать формулировки в справочнике без изменения кода. LLM-ответы менее предсказуемы с точки зрения педагогической безопасности языка.

Точность привязки подсказки к строке кода достигается через узлы AST с позицией в исходном тексте. Regex-подход не дает гарантий точности позиции.

## Последствия

Поддержка новых языков требует добавления соответствующей Tree-sitter грамматики и нового справочника шаблонов для этого языка. Это плановая задача при расширении платформы на JavaScript и Lua.

Справочник шаблонов является отдельным ресурсом, который поддерживается независимо от кода. Изменение формулировки подсказки не требует пересборки сервиса при реализации hot-reload справочника.

## Риски

Справочник шаблонов покрывает конечное множество типов ошибок. Нестандартная ошибка новичка может не получить качественной подсказки. Снижение риска: мониторинг случаев fallback без подсказки, итеративное пополнение справочника после пилотного тестирования.

LLM-слой добавляет зависимость от конфигурации окружения. Снижение риска: явная документация переменных окружения для LLM и graceful fallback до шаблонного ответа при недоступности.

## Оценка результативности

Подход считается корректно реализованным, если при экспертной проверке педагогом не менее 80 процентов сгенерированных подсказок получают оценку не ниже 4 из 5, и p95-задержка ответа Hint Service не превышает 2000 мс при стандартной нагрузке.
